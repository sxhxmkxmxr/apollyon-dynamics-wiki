# Apollyon Wiki

A static HTML reference for investors, evaluators and due-diligence readers.
Open `index.html` in a browser, or serve the directory:

```sh
python3 -m http.server 8901     # from inside wiki/
```

## Tone

Doctrine pages are philosophical and may argue. Product, subsystem, strategy
and company pages are technical: state what the system does, mark estimates and
claims, give ranges where the figure is not yet measured, and leave out
superlatives ("dominates", "first", "zero", "unmatched").

## Design system

The wiki wears Wikipedia's Vector 2022 skin, reproduced on the Codex design
tokens: white ground, `#202122` text, `#36c` links, `#a2a9b1` rules, serif
headings (Linux Libertine / Georgia) over system sans-serif text. Night mode
uses Codex's dark tokens. Colours are CSS variables on `:root`; the old token
names (`--ink`, `--red`, `--mono`…) are kept as aliases so inline styles in
pages still theme.

Page chrome, all written by `site_shell.py`: header with main menu, logo and
search; contents on the left (built from the article's `section > h2` and
direct `h3` headings); title, Article / Talk and Read / View source / View
history tabs; Tools and Appearance menus on the right (text size, width,
light / dark / automatic). Each menu can be pinned or hidden, and the choice is
stored in `localStorage` under `mwclientpreferences`, as MediaWiki stores its
clientprefs. Below 1120px the contents move to a button beside the title;
below 720px search collapses to an icon.

Article furniture maps onto Wikipedia templates: `.hero-plate` is an infobox;
figures and `.blueprint-plate`s are thumbnails (photographs float right,
diagrams span the column); tables are wikitables; `.note` and `.callout` are
message boxes; `.quotebar` is a Cquote; `.cards` are Main Page boxes;
`.team-grid` is a gallery; `.pill` and `.dep-badge` use the {{Yes}} / {{Partial}}
/ {{No}} cell colours; `.prov` markers render like [citation needed]. Every page
ends with a succession box (reading order), a navbox and its category.

Behaviour, all in `js/wiki.js`: page previews on internal links, search
suggestions from `wiki-map-data.js` (Enter on an exact title goes straight to the
page), the media viewer on every figure (`#/media/File:…` URLs), a sticky
header, `[edit]` links, and `?action=edit` (view source), `history`, `info`,
`cite`, `whatlinkshere` and `talk` views. It all works from `file://` too.

Diagrams are drawn light (see `gen_visuals.py`) and inverted in night mode, as
Wikipedia's `skin-invert` does. New hand-drawn SVGs should use the same light
palette and carry `role="img"` so night mode inverts them.

**Do not regress** the war timeline with its hanging case files (`.war-*` in
`css/wiki.css`, JS at the bottom of `index.html`).

## Build tools (`scripts/`)

| Script | Purpose |
|---|---|
| `site_shell.py` | Writes the Vector 2022 shell around every article (the content between `<!-- article:start -->` and `<!-- article:end -->`): header, main menu, contents, tabs, Tools and Appearance menus, succession box, navbox, category, footer, sticky header. Reads each page's title (`h1#firstHeading`) and grey subtitle (`#mw-content-subtitle`) back from the page, so edit those in place; page-specific scripts go between `<!-- page-scripts:start/end -->`. Adds MediaWiki-style ids to `h3`s that lack one, writes the `special/` pages and the three `js/wiki-*-data.js` files (history from git). `SIDEBAR_GROUPS` is the main menu and the reading order the succession box follows. Run after any edit. |
| `gen_visuals.py` | Regenerates every chart and diagram into `assets/visuals.json`. Chart data (prices, ranges, product names) lives here; change it here first. |
| `inline_visuals.py` | Refreshes inlined SVGs in pages: fills `<!-- VISUAL:name -->` placeholders and re-replaces embedded SVGs by aria-label. |
| `gen_full_record.py` | Regenerates `strategic-dependency/full-record.html` from `js/dependency_corpus_data.js`. |
| `verify_links.py` | Checks every link and anchor across all pages. Must report 0 errors. |

Each topic has one owning page; other pages summarise it in a paragraph and
link there. Owners: strike economics, salvo model and requirement sheet →
trajectory; market, exports and channels → market; head-to-head comparisons and
the three strike philosophies → competitive; testimonials and full chronology →
history; each subsystem → its subsystem page.

Build order after editing content or generator:

```sh
python3 scripts/gen_visuals.py
python3 scripts/inline_visuals.py
python3 scripts/site_shell.py
python3 scripts/verify_links.py
```
